# 📘 Exercícios FACCAT em Java

Este repositório contém a resolução dos **60 exercícios de lógica de programação da FACCAT**, desenvolvidos em **Java**, com foco no aprendizado progressivo dos principais conceitos da linguagem e da lógica computacional.

Os exercícios foram resolvidos como parte do meu processo de estudos, evoluindo do básico até estruturas um pouco mais avançadas, sempre priorizando clareza, organização e boas práticas.

---

## 🎯 Objetivo

* Praticar **lógica de programação**
* Fixar conceitos fundamentais do **Java**
* Desenvolver raciocínio para resolução de problemas
* Criar uma base sólida para estudos futuros em programação

---

## 🧠 Conteúdos Abordados

Ao longo dos 60 exercícios, foram trabalhados os seguintes conceitos:

* ✅ Entrada e saída de dados (`Scanner`, `System.out.println`)
* ✅ Variáveis e tipos primitivos
* ✅ Operadores aritméticos e relacionais
* ✅ Estruturas condicionais (`if`, `else`, `else if`)
* ✅ Estruturas de repetição:

  * `while`
  * `do while`
  * `for`
* ✅ Validação de dados
* ✅ Contadores e acumuladores
* ✅ Trabalhando com **arrays (vetores)**
* ✅ Resolução de problemas matemáticos e lógicos

---

## 📂 Organização dos Exercícios

Cada exercício está implementado em uma **classe Java separada**, seguindo o padrão:

```
exercicioXXFaccat.java
```

Onde `XX` representa o número do exercício conforme a lista da FACCAT.

Exemplos:

* `exercicio01Faccat.java`
* `exercicio20Faccat.java`
* `exercicio59Faccat.java`
* `exercicio60Faccat.java`

---

## ▶️ Como Executar os Exercícios

1. Certifique-se de ter o **Java JDK** instalado
2. Clone este repositório:

   ```bash
   git clone <git clone <https://github.com/FabioRoberto-ppt/LogicaDeProgramacaoEmJava.git>>
   ```
3. Abra o projeto em uma IDE (IntelliJ, Eclipse, VS Code, etc.)
4. Execute a classe desejada pelo método `main`
